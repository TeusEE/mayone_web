# MAY.ONE 프론트엔드 스타일 가이드

작성일: 2026-09-27  
디자인·브랜드 카피 기준: [origin_source/mayone_homepage.html](../origin_source/mayone_homepage.html)  
제품 동작·접근성 기준: [fe-prd.md](./fe-prd.md)

이 문서는 기존 앱의 임시 시각안을 유지하는 문서가 아닙니다. 원본 HTML의 디자인 언어를 앱의 공통 컴포넌트와 반응형 화면에 적용하기 위한 구현 기준입니다. 원본과 PRD가 다른 경우 원본 HTML의 브랜드 표현을 따르고, 실제 링크·운영정보·접근성 동작은 PRD의 공개 규칙을 따릅니다.

## 시각 언어

- 분위기는 따뜻한 아이보리와 종이색, 잉크색 본문, 제한된 골드 포인트로 만듭니다.
- 큰 영문·브랜드 제목에는 `Georgia, "Noto Serif KR", serif` 계열을 쓰고, 본문에는 시스템 한글 산세리프를 씁니다.
- 화면은 최대 폭 1180px, 얇은 선, 평면 카드와 충분한 여백을 사용합니다. 기본 카드 모서리는 직각이며 그림자와 장식용 둥근 pill을 쓰지 않습니다.
- 살롱과 마켓은 좌우 분할 소개를 사용합니다. 시장 영역은 어두운 색면, 마지막 행동 영역은 밝은 아이보리, 푸터는 거의 검정에 가까운 색면으로 구분합니다.
- 실제 사진·로고를 받기 전까지는 원본 HTML의 CSS visual 패널을 사용할 수 있습니다. 이 패널은 사진이나 공식 로고처럼 설명하지 않습니다.

## 레이아웃

- 공통 콘텐츠 폭은 1180px, 데스크톱 좌우 여백은 28px, 좁은 화면은 20px을 기준으로 합니다.
- 헤더는 72px 높이의 sticky 바, 흰 종이색 반투명 배경, blur와 얇은 하단 선으로 구성합니다. 메뉴 순서는 `SALON`, `HARU ACADEMY`, `MAY.ONE MARKET`, `RECRUIT`, `ABOUT US`입니다.
- 히어로는 데스크톱에서 화면 높이 약 82%, 모바일에서 약 75%를 사용하고 가운데 정렬합니다.
- 주요 구역 간 위아래 간격은 데스크톱 약 110px, 모바일 약 75px입니다.
- 데스크톱 그리드는 성장 시스템 5열, 교육 원칙 4열, 생태계 3열을 기준으로 합니다. 태블릿에서는 읽기 폭에 맞춰 열을 줄이고 800px 이하에서는 한 열로 쌓습니다.
- 소개 split은 `1.05fr / 0.95fr`, 간격 약 70px입니다. 모바일에서는 본문 다음 visual 순서로 한 열이 됩니다.
- 카드 기본 패딩은 30px, 최소 높이는 약 190px이며 밝은 종이색 면과 1px 선만 사용합니다.

## 메인 콘텐츠 순서

원본 HTML의 순서와 공식 문구를 유지합니다.

1. 히어로와 살롱·HARU·마켓 바로가기
2. `ONE BRAND. ONE SYSTEM.` 성장 흐름 `SALON → SYSTEM → EDUCATION → ACADEMY → BUSINESS`
3. `MAY.ONE HAIR` 소개
4. `MAY.ONE SYSTEM`의 다섯 성장 요소
5. `HARU` 소개, 교육 원칙 네 가지, 교육 분야 다섯 가지
6. 어두운 `MAY.ONE MARKET` 소개
7. `GROW WITH MAY.ONE`과 네 단계 성장 경로
8. `EVERYTHING IS CONNECTED.` 사업 연결 카드 세 가지
9. `Learn. Grow. Lead.` 마지막 CTA

연혁, 지점 요약, 강사진, 산학협력 프로그램, 후기, 임의의 추가 비전 카피를 메인 사이에 넣지 않습니다. 상세 운영 정보는 각각의 독립 경로에서 공개 검증 상태에 따라 다룹니다.

## 링크·상태·접근성

- 원본 HTML에 있는 `href="#"`는 그대로 사용하지 않습니다. 동작하는 내부 경로로 연결하거나 공개 자료가 없을 때는 실제 `disabled` 버튼을 씁니다.
- 스마트스토어 URL은 중앙 링크 레코드가 공개·검토 완료된 경우만 새 탭으로 엽니다. 예약·교육·채용도 공개 레코드와 유효한 URL을 확인한 뒤 활성화합니다.
- 모바일 메뉴의 열기·닫기·Escape·포커스 제한과 복귀, 본문 스크롤 잠금을 유지합니다. 앵커에는 sticky 헤더 높이만큼 스크롤 여유를 둡니다.
- 비활성 CTA에는 왜 진행할 수 없는지 주변 설명을 제공합니다. 링크·버튼은 키보드로 접근 가능하고 눈에 보이는 focus 상태를 갖습니다.
- `prefers-reduced-motion` 설정에서는 부드러운 스크롤과 움직임을 줄입니다.
