# 비주얼살롱 유사 서비스 제작 참고

> 보관용 관찰 자료입니다. 현재 MAY.ONE의 디자인·카피·메인 정보 구조를 정하는 기준이 아닙니다. 구현은 [원본 MAY.ONE 홈페이지](../origin_source/mayone_homepage.html)와 [프론트엔드 PRD](./fe-prd.md)를 따릅니다.

## 목적과 참고 범위

- 참고 사이트: [비주얼살롱](https://www.visualsalon.co.kr/)
- 참고 목적: 헤어 케어·살롱 서비스 랜딩 페이지의 정보 구조, 비주얼 방향, 콘텐츠 배치와 반응형 제작 기준을 정리합니다.
- 관찰 범위: 홈페이지 데스크톱 화면과 반응형 모바일 화면을 브라우저에서 확인했습니다. 모바일 확인은 브라우저 뷰포트를 약 390px로 줄여 진행했으며, 페이지 콘텐츠 폭은 약 375 CSS px로 표시됐습니다.
- 이 문서에 적힌 비주얼살롱의 색상·레이아웃 관찰은 이번 MAY.ONE 구현의 시각 기준에 사용하지 않습니다.

## 페이지의 핵심 흐름

참고 사이트는 독자 기술인 GMR(결마지)을 소개한 뒤, 모발 변화 설명과 시술 전후 사례, 고객 후기, 지점 정보로 이어지는 브랜드 랜딩 페이지입니다.

1. **고정 헤더** — 로고, 결마지(GMR), BRAND, SALON, COMMUNITY 등 주요 메뉴와 로그인·MY·회원가입·검색
2. **히어로** — 긴 머리 모델 사진과 “What is GMR” 메시지, 기술을 설명하는 짧은 문구
3. **기술 소개** — 기술의 차별점과 모발 매크로 이미지를 좌우로 배치하고 상세 페이지 CTA 제공
4. **모발 변화 설명** — 손상 모발과 솔루션 이미지를 비교하고 기대 효과를 설명
5. **브랜드 메시지** — “피부엔 써마지, 머리엔 결마지” 문구와 흑백 헤어 이미지
6. **Protein Reset Principle** — 케어 원리 소개
7. **시술 전후** — Before/After 사진을 나란히 배치
8. **GMR 후기** — 별점과 짧은 후기를 구분선으로 정리
9. **지점 목록** — 지점 사진, 지점명, NEW 표시와 예약 유도
10. **푸터** — 회사 정보, 정책 링크, SNS 링크

## 데스크톱 화면에서 확인한 디자인

### 헤더와 내비게이션

- 흰색 배경의 얇은 상단 헤더가 페이지를 스크롤하는 동안 고정됩니다.
- 왼쪽에는 워드마크와 가로형 메뉴, 오른쪽에는 계정·검색 기능이 배치되어 있습니다.
- 본문과 분리된 단정한 헤더로, 사진 중심의 콘텐츠가 먼저 보이도록 합니다.

### 히어로와 콘텐츠 배치

- 히어로는 밝은 회색 배경 위에 모델 사진과 큰 영문 제목을 좌우로 나눈 에디토리얼 구성입니다.
- 사진 아래에는 반투명 베이지 설명 영역이 겹쳐 있고, 짧은 요약 문구가 들어갑니다.
- 기술 소개 영역은 연한 웜그레이 바탕에 텍스트와 가로형 이미지를 나란히 두며, 어두운 갈색의 둥근 버튼으로 상세 페이지를 안내합니다.
- 모발 클로즈업, 흑백 모델 사진, 시술 전후 사진을 크게 사용해 설명을 시각적으로 뒷받침합니다.
- 후기 영역은 베이지 톤 배경 위에 흰 패널을 얹고, 후기별 별점·문장·구분선을 반복합니다.
- 지점은 데스크톱에서 3열 이미지 그리드로 구성되어 있습니다. 카드 위에는 NEW 배지와 예약 링크가 나타납니다.

### 색상·사진·타이포그래피

- **색상 방향:** 흰색, 연회색, 베이지를 기본으로 하고 제목·버튼에는 검정과 짙은 갈색을 사용합니다.
- **이미지 방향:** 윤기 있는 긴 머리, 손상 모발의 질감, 모발 단면을 연상시키는 매크로 비주얼, 전후 사진을 활용합니다.
- **타이포그래피 방향:** 한글 산세리프 제목을 중심으로 하고, 영문 키워드는 큰 세리프체나 이탤릭체로 대비를 줍니다.
- **밀도:** 섹션 사이 여백이 넓고, 문장 길이는 짧습니다. 장식 요소와 카드 테두리는 최소화되어 있습니다.

## 유사 서비스를 만들 때 권장하는 정보 설계

참고 사이트의 분위기와 전환 흐름은 참고하되, 서비스에 맞는 고유한 브랜드 메시지와 이미지로 구성합니다.

- 첫 화면에서 서비스가 해결하는 문제와 대표 결과를 한 문장으로 제시합니다.
- 기술이나 프로그램 설명은 **핵심 문구 → 짧은 설명 → 대표 이미지 → 자세히 보기** 순서로 구성합니다.
- 결과 사례에는 전후 기준, 시술·프로그램 설명, 개인차 안내를 함께 둡니다.
- 후기는 실제 고객의 짧은 경험을 중심으로 보여주고, 후기에서 지점·예약 경로로 이어지게 합니다.
- 지점 카드에는 사진, 지점명, 위치 또는 영업 정보, 예약 버튼을 한 묶음으로 둡니다.
- 메뉴는 브랜드 소개, 서비스/기술, 지점, 커뮤니티처럼 사용자의 주요 목적을 기준으로 단순화합니다.

## 모바일 화면에서 확인한 반응형 배치

아래 내용은 약 375 CSS px 너비의 실제 반응형 화면에서 확인했습니다.

- **헤더:** 데스크톱의 한 줄 헤더가 두 줄 구조로 바뀝니다. 첫 줄은 왼쪽 햄버거, 가운데 로고, 오른쪽 검색 아이콘이고, 둘째 줄은 결마지(GMR)·BRAND·SALON·COMMUNITY를 가로로 보여줍니다. 현재 메뉴에는 밑줄 표시가 있습니다. 스크롤해도 이 두 줄 헤더가 화면 위에 고정됩니다.
- **히어로:** 데스크톱의 모델 사진·영문 제목 좌우 배치가 세로형으로 전환됩니다. 작은 브랜드 표식과 “What is GMR?” 제목, 한글 메시지를 먼저 보여주고 세로형 모델 이미지를 아래에 둡니다. 요약 문구는 이미지 다음의 짙은 회색 패널 안에 흰색으로 표시합니다.
- **기술 소개:** 제목과 설명 다음에 매크로 이미지를 세로로 배치합니다. 상세 CTA는 본문 뒤에 가운데 정렬됩니다.
- **모발 변화:** 데스크톱에서 텍스트와 Before/After 이미지가 나란히 보이던 구성이 한 열로 바뀝니다. 설명 다음에 BEFORE, AFTER 이미지를 각각 라벨과 함께 세로로 배치합니다.
- **브랜드 메시지·Protein Reset:** 설명과 흑백 헤어 이미지, 케어 원리와 전후 사진이 한 열로 이어집니다. Protein Reset 구간은 연회색 패널 안에 제목·설명·BEFORE/AFTER 사진을 순서대로 배치하고, 끝에 결과 차이 안내를 둡니다.
- **후기:** 밝은 베이지·회색 계열 배경에 흰색 둥근 패널을 사용합니다. 후기와 별점은 세로로 읽게 배치됩니다. 모바일 화면에서는 GMR Review 제목이 있는 후기 영역이 지점 목록 직전에도 한 번 더 나타나 데스크톱과 구성이 다르게 보였습니다. 유사 서비스를 제작할 때는 모바일 전용 후기 영역이 의도된 것인지 확인하고, 같은 후기가 중복 노출되지 않도록 콘텐츠 노출 조건을 정합니다.
- **지점 목록:** 데스크톱 3열 그리드가 한 열로 전환됩니다. 모바일 화면에서는 지점 사진이 거의 콘텐츠 폭 전체를 차지하고, NEW 표시는 사진 왼쪽 위, 지점명은 이미지 아래 가운데에 놓입니다. 확인된 지점 카드 8개가 세로로 이어집니다.
- **푸터:** 어두운 회색 바탕에 정책 링크, 회사 정보, SNS 아이콘을 한 열로 쌓습니다. 주소와 연락처는 좁은 폭에 맞춰 줄바꿈됩니다.

### 모바일을 구현할 때 적용할 점

- 작은 화면에서도 상단 주요 메뉴를 바로 탐색할 수 있도록 두 줄 헤더 또는 햄버거 메뉴와 가로 탭 메뉴를 조합할 수 있습니다.
- 데스크톱의 좌우 분할 콘텐츠는 한 열로 전환하되, 설명과 이미지의 순서가 메시지를 이해하기 쉽게 유지되도록 합니다.
- 전후 비교는 세로 배치에서도 각 사진의 라벨과 크기를 충분히 확보합니다.
- 지점 카드 이미지를 크게 유지하고 카드 사이 여백을 둬 한 지점씩 구분되게 합니다.
- 실제 구현에서는 375px 안팎뿐 아니라 더 좁은 화면과 태블릿 폭에서도 메뉴, 제목, 이미지 초점, 후기, 푸터 줄바꿈을 확인합니다.

### 반응형 확인 기준

제작 후에는 최소한 데스크톱, 태블릿, 모바일 폭에서 다음을 확인합니다.

- 헤더 메뉴가 본문을 가리거나 두 줄로 깨지지 않는지
- 히어로 제목과 모델 이미지의 초점이 잘리지 않는지
- 좌우 분할 섹션이 모바일에서 자연스러운 읽기 순서로 쌓이는지
- 전후 이미지와 라벨이 비교하기 쉬운 크기로 보이는지
- 지점 카드와 CTA가 터치하기 충분한 크기인지
- 후기 문장과 푸터 정보가 가로 스크롤 없이 읽히는지

## 구현용 구성요소 체크리스트

- 반응형 고정 헤더와 모바일 메뉴

- 텍스트·이미지 분할 소개 섹션
- 모발 변화 설명과 전후 비교 컴포넌트
- 별점·후기 카드 목록
- 지점 카드 그리드와 예약 링크
- SNS·정책 링크가 포함된 푸터
