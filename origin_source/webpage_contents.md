## 2. 홈페이지의 목적과 방문자별 핵심 행동

### 2.1 브랜드의 중심 메시지

> 사람을 아름답게, 사람을 성장하게.

MAY.ONE은 살롱, 교육, 마켓을 통해 고객의 아름다움과 미용인의 성장을 연결하는 브랜드로 소개한다. 첫 화면에서 세 사업을 구분할 수 있게 하고, 이후 화면에서 실제 예약·교육 확인·구매·지원으로 이어지게 한다.

| 헤어살롱 이용 고객 | 가까운 지점, 디자이너, 스타일, 방문 정보 | 지점 선택 → 디자이너·스타일 확인 → 네이버 예약 |

### 2.2 문구의 일관성

- 브랜드 표기: `MAY.ONE`, `메이원`, `MAY.ONE HAIR`, `메이원헤어`, `MAY.ONE MARKET`, `메이원마켓`.
- 아카데미의 홈페이지 기본 표기: 원고에 맞춰 `HARU 미용사관학교`. PDF의 `하루미용사관학교`와 병용할 필요가 있으면 공식 표기를 먼저 확정한다.
- 영어는 섹션 이름과 브랜드 슬로건에 사용하고, 서비스 설명과 행동 버튼은 한국어로 작성한다.
- 같은 행동에는 같은 이름을 쓴다. `교육 일정 보기`, `수강 신청하기`, `지점 찾기`, `네이버 예약하기` 등을 화면마다 통일한다.
- 성장을 설명할 때 교육·상담·실습·고객관리·운영처럼 구체적인 활동을 함께 제시한다.

## 3. 메뉴와 페이지 구성

### 3.1 상단 메뉴

기존 HTML의 메뉴를 기본으로 유지하되, 방문자가 행동을 예상할 수 있게 이름과 목적지를 정리한다. 원고의 `MAY.ONE` 메뉴는 좌측 로고의 홈 이동으로 구현할 수 있다.

| 항목 | 노출 이름 | 메인 화면 목적지 | 포함 내용 |
| --- | --- | --- | --- |
| 로고 | MAY.ONE | `#top` | 첫 화면으로 이동 |
| 살롱 | SALON | `#hair` | 살롱 소개, 상담 철학, 지점 찾기 |
| 교육 | HARU | `#haru` | 아카데미 소개, 교육 체계, 강사진, 일정, 산학협력 |
| 마켓 | MARKET | `#market` | 마켓 소개, 공식 스토어, 대표 상품 |
| 채용 | RECRUIT | `#recruit` | 성장 경로, 채용공고, 입사지원 |
| 브랜드 | ABOUT | `#about` | 브랜드 시작, 시스템, 연혁, 생태계, 비전 |

메뉴는 데스크톱에서 한 줄로, 모바일에서는 메뉴 버튼을 눌러 여는 목록으로 제공한다. 현재 HTML은 800px 이하에서 메뉴를 숨기기만 하므로 모바일에서도 위 목적지에 접근할 수 있는 구성이 필요하다.

### 3.2 메인 화면의 권장 흐름

원고의 17개 항목은 모두 반영하되, 관련 내용은 같은 영역 안의 소제목으로 묶는다. 각각을 큰 화면 하나로 만들면 교육 설명이 반복되고 페이지가 길어질 수 있다.

### 3.3 상세 화면이 필요한 콘텐츠

다음 주소는 **제안 경로**다. 기존 HTML에 구현된 페이지가 아니며, 사용 프레임워크와 화면 방식에 따라 변경할 수 있다. 초기에는 일부를 접근 가능한 상세 패널로 제공해도 된다.

| 화면 | 제안 경로 | 메인에서 연결되는 내용 |
| --- | --- | --- |
| 지점 목록 | `/salon` | 전체 지점, 지역 선택, 지점 검색 |
| 지점 상세 | `/salon/{branch-id}` | 위치·운영시간, 디자이너, 스타일, 예약 |
| 교육 목록 | `/haru/classes` | 분야별 교육, 모집 상태, 일정 |
| 교육 상세 | `/haru/classes/{class-id}` | 강사, 교육 내용, 대상, 비용, 신청 |
| 산학협력 안내 | `/haru/cooperation` | 협력 프로그램과 문의 |
| 채용 목록 | `/recruit` | 모집 지점·직무와 공고 |
| 채용 상세 | `/recruit/{job-id}` | 조건, 절차, 마감, 지원 |
| 브랜드 상세 | `/about` | 연혁, 시스템, 운영진, 비전 |

마켓은 홈페이지에서 별도의 결제 화면을 만들지 않고 HTML에 있는 외부 스토어 연결 방식을 사용한다. 교육 신청·입사지원·문의도 운영 중인 공식 외부 양식이 있다면 해당 링크를 우선 연결한다.

## 4. 메인 화면의 콘텐츠 상세

### 4.1 MAIN — 브랜드 첫 화면

**목적:** 브랜드의 약속과 세 가지 서비스를 첫 화면에서 이해하게 한다.

**노출 문구안**

- 상단 문구: `BEAUTY · EDUCATION · GROWTH`
- 브랜드명: `MAY.ONE`
- 메인 제목: `사람을 아름답게, 사람을 성장하게.`
- 설명:

> 고객에게는 더 나은 디자인을,
> 미용인에게는 더 큰 성장의 기회를 제공합니다.
>
> 살롱에서의 경험을 교육과 시스템으로 만들고,
> 미용 현장에 필요한 제품과 서비스를 연결합니다.

- 서비스 요약: `MAY.ONE HAIR · HARU 미용사관학교 · MAY.ONE MARKET`
- 버튼: `지점 찾기`, `HARU 교육 일정 보기`, `메이원마켓 바로가기`.

**필요한 화면 요소**

- 브랜드 로고와 제목을 최우선으로 배치한다.
- 실제 살롱이나 교육 현장 사진을 배경 또는 보조 이미지로 사용한다. 사진 위 문구가 읽히도록 대비를 확보한다.
- 세 서비스는 이름만 나열하지 않고 `살롱`, `교육`, `마켓`이라는 한국어 설명을 함께 제공한다.
- `지점 찾기`는 지점 목록으로 연결한다. 지점 선택 이전에는 특정 매장의 예약으로 바로 이동하지 않는다.

### 4.2 ABOUT MAY.ONE — 브랜드 소개

**목적:** 살롱에서 시작한 브랜드가 교육과 마켓으로 연결되는 이유를 설명한다.

**노출 문구안**

- 상단 문구: `ONE BRAND. ONE SYSTEM.`
- 제목: `하나의 살롱에서 하나의 미용 생태계로.`
- 본문:

> 메이원은 살롱 현장에서 시작했습니다.
> 현장에서 만난 문제와 고민을 교육과 시스템으로 풀어가며,
> 디자이너가 성장할 수 있는 환경을 만들어왔습니다.
>
> 사내 교육은 전문 아카데미로 이어지고,
> 그 경험은 미용 현장에 필요한 제품과 서비스를 연결하는 마켓으로 확장됩니다.

**성장 구조 콘텐츠**

| 단계 | 노출 설명 |
| --- | --- |
| SALON | 현장에서 고객과 디자이너를 만납니다. |
| SYSTEM | 함께 성장할 수 있는 기준을 만듭니다. |
| EDUCATION | 기술과 현장의 노하우를 교육합니다. |
| ACADEMY | 전문적인 미용교육으로 확장합니다. |
| MARKET | 현장에 필요한 제품과 서비스를 연결합니다. |

하단 문구: `SALON · EDUCATION · MARKET — 미용인의 성장을 하나로 연결합니다.`

기존 HTML은 마지막 단계를 `BUSINESS`로 표시한다. 전체 원고와 사업 이름의 일관성을 위해 홈페이지의 확장 구조는 `MARKET`으로 정리한다. PDF의 기존 성장 구조인 `SALON → SYSTEM → EDUCATION → ACADEMY`와 이후 마켓 확장을 구분해서 설명한다.

### 4.3 MAY.ONE HAIR — 살롱 소개와 상담 철학

**목적:** 고객이 메이원의 디자인 접근을 이해하고 지점을 선택하게 한다.

**노출 문구안**

- 상단 문구: `MAY.ONE HAIR`
- 영어 제목: `BEAUTY BEYOND STYLE`
- 한국어 제목: `아름다움을 만드는 것을 넘어 사람의 성장을 만듭니다.`
- 소개:

> 메이원헤어는 고객에게 어울리는 디자인을 제안하고,
> 디자이너가 자신의 가능성을 키워갈 수 있는 성장형 헤어살롱 브랜드입니다.
> 고객과 디자이너가 함께 성장하는 살롱을 만들어갑니다.

**상담 철학 콘텐츠**

- 소제목: `좋은 디자인은 좋은 상담에서 시작됩니다.`
- 설명:

> 얼굴형, 두상, 모질, 라이프스타일을 이해하고
> 고객 한 사람에게 어울리는 디자인을 제안합니다.
> 일상에서 손질하는 방법까지 고려해 나에게 맞는 스타일을 함께 찾습니다.

마지막 문장의 손질 안내는 작성 제안이므로 실제 상담 서비스와 일치하는지 확인한다.

| 상담 항목 | 카드 설명안 |
| --- | --- |
| 얼굴형 | 얼굴의 비율과 인상에 어울리는 디자인 |
| 두상 | 두상의 형태와 볼륨을 고려한 디자인 |
| 모질 | 모발의 특성과 상태를 이해한 시술 제안 |
| 라이프스타일 | 평소 스타일과 관리 습관을 고려한 상담 |

**필요 자료와 행동**

- 실제 매장 내부, 상담 장면, 시술 장면, 완성 스타일 사진.
- 버튼: `가까운 지점 찾기` → `#locations`, `메이원 채용 보기` → `#recruit`.
- 기존 HTML의 `MO` 그래픽은 임시 비주얼이므로 실제 브랜드 이미지로 교체할 수 있다.

### 4.4 MAY.ONE SYSTEM — 디자이너 성장 시스템

**목적:** 메이원의 성장 환경을 구체적인 교육·업무 영역으로 보여준다.

**노출 문구안**

- 제목: `디자이너가 성장해야 브랜드가 성장합니다.`
- 설명:

**교육 상세 화면 순서**

1. 교육 이미지와 교육명, 모집 상태.
2. 강사 이름·프로필·주요 이력.
3. 교육 소개와 수업 종료 후 배우게 될 내용.
4. 수강 대상과 필요한 사전 경험.
5. 회차별 커리큘럼, 이론·시연·실습 방식.
6. 일정, 교육장, 정원, 모집 마감.
7. 교육비, 재료·모델·도구 등 포함 내역과 준비물.
8. 운영팀이 확정한 신청·결제 방식과 취소·환불 안내.
9. 수강 신청 버튼과 교육 문의 수단.

원고의 기본 순서인 `교육 이미지 → 강사 → 교육내용 → 일정 → 교육비 → 신청`을 유지하면서 신청 판단에 필요한 정보를 보완한다. 정원·잔여석을 실제로 관리하지 않는다면 잔여석 숫자를 표시하지 않는다.

**목록의 상태별 문구안**

- 모집 중인 강의가 없는 경우: `현재 신청 가능한 교육이 없습니다.`
- 선택한 분야에 강의가 없는 경우: `해당 분야의 교육이 없습니다. 다른 분야를 선택해주세요.`
- 마감된 교육: 상태 `신청 마감`, 신청 버튼 비활성화.
- 종료된 교육: 상태 `교육 종료`, 지난 교육으로 분류.
- 일정을 아직 받지 못한 제작 단계: 화면에는 임의 날짜를 넣지 않고 내부 자료 준비 목록에 기록한다.

`전체 교육 일정 보기`와 강의별 `수강 신청하기`는 역할이 다르다. 하나의 강의 신청은 반드시 해당 강의 정보와 연결한다.

## 5. 신청·지원·문의 화면의 내용

별도 양식을 홈페이지에 구현할지는 운영 방식에 따라 결정한다. 외부 공식 양식이 있다면 해당 양식으로 연결하고, 홈페이지 안에서 접수하려면 실제 저장·전달 수단을 마련한다. 화면만 있는 상태에서 접수 완료를 표시하지 않는다.

### 5.1 교육 신청

| 항목 | 필수 여부 제안 | 작성 안내 |
| --- | --- | --- |
| 선택 교육 | 필수 | 교육 상세에서 선택한 강의명과 일정 표시 |
| 이름 | 필수 | 신청자 이름 |
| 연락처 | 필수 | 교육 안내를 받을 연락처 |
| 현재 단계 | 운영 필요 시 | 학생 / 인턴 / 디자이너 / 원장 등 |
| 소속 | 선택 | 학교 또는 근무 살롱 |
| 문의·요청 | 선택 | 교육과 관련한 문의 |
| 개인정보 안내·동의 | 수집 방식에 맞춰 확정 | 실제 수집 항목·이용 목적·보유기간 안내 연결 |

- 제출 버튼: `수강 신청하기`.
- 정상 접수 후 문구안: `수강 신청이 접수되었습니다. 수강 확정과 결제 안내는 운영팀 안내를 확인해주세요.`
- 결제가 별도로 필요한 경우 신청 접수와 수강 확정을 구분해 설명한다.
- 필수값 오류: `이름을 입력해주세요.`, `연락처를 확인해주세요.`
- 접수 실패: `신청을 접수하지 못했습니다. 잠시 후 다시 시도해주세요.`와 실제 문의 수단.

### 5.2 입사지원

| 항목 | 필수 여부 제안 | 작성 안내 |
| --- | --- | --- |
| 선택 공고 | 필수 | 모집 지점·직무 표시 |
| 이름·연락처 | 필수 | 지원자와 안내 받을 연락처 |
| 경력 | 공고에 따라 | 신입·경력, 경력 기간 |
| 이메일 | 안내 방식에 따라 | 지원 결과를 받을 주소 |
| 이력서 | 공고에 따라 | 실제 접수 가능한 파일 형식·용량 안내 |
| 포트폴리오·SNS URL | 선택 | 지원자의 작업을 볼 수 있는 링크 |
| 자기소개·지원 동기 | 운영 방식에 따라 | 공고에서 요구하는 범위 |
| 개인정보 안내·동의 | 수집 방식에 맞춰 확정 | 채용 목적에 맞는 안내 연결 |

제출 버튼: `입사지원서 제출`. 정상 접수 문구안: `지원서가 접수되었습니다. 전형 안내는 등록한 연락처로 전달됩니다.` 실제 안내 절차가 다르면 문구를 수정한다.

### 5.3 산학협력 문의

| 항목 | 필수 여부 제안 | 작성 안내 |

| 기관·학과명 | 필수 | 문의 기관 |
| 담당자 이름·직책 | 이름 필수 | 협의 담당자 |
| 연락처·이메일 | 최소 한 수단 필수 | 실제 답변 가능한 연락 수단 |
| 관심 프로그램 | 선택 | 특강 / 기술교육 / 현장 경험 / 취업 연계 / 공동 프로그램 |
| 희망 시기·인원 | 선택 | 기획 중인 범위 |
| 문의 내용 | 필수 | 협의하고 싶은 내용 |
| 개인정보 안내·동의 | 수집 방식에 맞춰 확정 | 문의 처리에 필요한 안내 연결 |

제출 버튼: `산학협력 문의 보내기`. 정상 접수 문구안: `문의가 접수되었습니다. 담당자가 확인 후 안내드리겠습니다.` 응답 기한은 운영팀이 실제로 지킬 수 있는 기준이 있을 때만 표시한다.

## 6. 자주 묻는 질문과 공통 안내

FAQ는 운영팀이 답변을 확정한 항목만 공개한다. 아래는 필요한 질문 목록이며 실제 답변은 제공되지 않았다.

| 영역 | 필요한 질문 |
| --- | --- |
| 살롱 | 예약은 어디에서 하나요? 디자이너를 선택할 수 있나요? 주차가 가능한가요? 예약 변경은 어떻게 하나요? |
| HARU | 누구나 수강할 수 있나요? 사전 경험이 필요한가요? 준비물·모델이 필요한가요? 결제와 취소는 어떻게 하나요? |
| 산학협력 | 어떤 기관이 문의할 수 있나요? 인원·장소·일정은 어떻게 협의하나요? |
| 채용 | 현재 어느 지점에서 모집하나요? 경력이 없어도 지원할 수 있나요? 지원 이후 절차는 무엇인가요? |
| 마켓 | 상품·배송 문의는 어디에서 하나요? → 실제 스마트스토어의 안내 채널로 연결 |

공통으로 필요한 문구는 외부 링크 안내, 신청 상태, 검색 결과 없음, 자료 준비 상태, 오류 안내다. 사용자는 어떤 행동을 할 수 있는지와 다음 단계가 무엇인지 알 수 있어야 한다.

## 9. 화면 표현과 모바일 콘텐츠 기준

- 기존 HTML의 아이보리·화이트·골드·짙은 글자 색을 기본 분위기로 사용한다. MARKET 영역은 기존의 어두운 배경을 활용할 수 있다.
- 서비스 소개는 제목, 짧은 설명, 관련 이미지, 행동 버튼 순서로 구성한다. 긴 원고는 소제목과 카드로 나누되 핵심 내용은 본문에서도 확인할 수 있게 한다.
- 모바일에서도 메뉴, 지점 찾기, 교육 일정, 신청·예약 버튼을 사용할 수 있게 한다.
- 지점·교육·채용 카드는 모바일에서 한 열로 읽히게 하고, 중요한 날짜·상태·비용을 숨기지 않는다.
- 성장 구조는 모바일에서 위에서 아래로 배치하며 각 단계에 한국어 설명을 붙인다.
- 긴 지점명과 강의명은 의미가 끊기지 않게 줄바꿈한다. 핵심 정보를 말줄임표로만 처리하지 않는다.
- 카드 안의 여러 버튼은 `상세 보기`와 `예약·신청`을 구분하고, 해당 지점·강의 이름을 접근 가능한 이름에 포함한다.
- 마켓 링크에는 외부 이동 안내를 제공한다. 이미지 안의 글자와 색상만으로 모집 상태를 전달하지 않는다.
- 폼에는 항상 보이는 항목 이름과 해당 입력 옆의 오류 설명을 제공한다. 상세 패널로 구현할 경우 제목, 닫기 버튼, 키보드 이동을 제공한다.

## 10. 검색 결과와 공유에 필요한 문구

### 10.1 메인 페이지

- 페이지 제목안: `MAY.ONE | 메이원헤어 · HARU 미용사관학교 · 메이원마켓`
- 설명안: `사람을 아름답게, 사람을 성장하게. 메이원헤어의 지점과 예약 정보, HARU 미용사관학교 교육 일정, 메이원마켓과 채용·산학협력 정보를 만나보세요.`
- 공유 제목안: `MAY.ONE — 사람을 아름답게, 사람을 성장하게.`
- 공유 이미지: 공식 로고와 대표 이미지, 한국어 메인 문구를 포함한 별도 이미지.

### 10.2 상세 페이지

| 화면 | 제목 형식 | 설명에 포함할 정보 |
| --- | --- | --- |
| 지점 상세 | `{지점명} \| MAY.ONE HAIR` | 확정 지역, 디자인 소개, 예약 안내 |
| 교육 상세 | `{교육명} \| HARU 미용사관학교` | 실제 대상, 강사, 확정 일정, 교육 내용 |
| 채용 상세 | `{지점명} {직무} 채용 \| MAY.ONE` | 실제 모집 직무, 지원 안내 |
| 산학협력 | `산학협력 프로그램 \| HARU × MAY.ONE` | 프로그램과 공식 문의 안내 |

공식 도메인은 미제공이므로 공유 URL과 대표 주소는 도메인 확정 후 지정한다. 교육·매장 정보는 이미지에만 넣지 않고 검색 가능한 본문으로 작성한다.

## 11. 프론트엔드에 전달할 반복 콘텐츠 항목

아래는 콘텐츠를 카드와 상세 화면에 일관되게 연결하기 위한 권장 데이터 항목이다. 저장 방식이나 API 구현을 정한 것은 아니다. 필수 정보가 없으면 담당자에게 자료를 요청하고, 선택 정보는 없는 영역을 숨긴다.

| 콘텐츠 | 필수 또는 핵심 항목 | 선택·확장 항목 |
| --- | --- | --- |
| 지점 | 고유 ID, 공식 지점명, 지역, 주소, 예약 URL, 운영 여부 | 대표 이미지, 운영시간, 휴무, 전화, 교통·주차, 지도 URL·좌표 |
| 디자이너 | 고유 ID, 소속 지점 ID, 이름, 직책·전문 분야 | 프로필 이미지, 소개, 디자이너 예약 URL, 스타일 목록 |
| 스타일 | 이미지, 스타일명, 시술 분야 | 담당 디자이너 ID, 설명, 연결 지점 ID |
| 강사 | 고유 ID, 이름, 역할·분야 | 사진, 소개, 주요 이력, 연결 강의 ID |
| 교육 | 고유 ID, 제목, 분야, 강사 ID, 교육 내용, 대상, 모집 상태. 신청 가능한 강의는 일정·장소·교육비·신청 수단·취소 안내도 필수 | 이미지, 상세 회차, 정원, 준비물 |
| 채용 | 고유 ID, 공고명, 지점 ID, 직무, 자격, 조건, 모집 상태. 모집 중인 공고는 지원 수단·문의처도 필수 | 마감일, 모집 인원, 전형, 제출 자료 |
| 협력 사례 | 기관명, 프로그램명, 내용 | 진행 시기, 이미지, 대상, 공개 가능한 결과 |
| 공통 링크 | 로고 홈 목적지, 공식 마켓 URL, 공식 문의 수단 | SNS, 정책, 대표 상품 URL |

반복 콘텐츠의 모집 상태와 날짜를 분리해 관리한다. 신청 가능 여부와 버튼은 실제 운영 상태에 맞춰 표시한다. 외부 URL이 없는 항목에 빈 링크나 임의 링크를 넣지 않는다.

## 12. 버튼과 목적지 정리

| 노출 위치 | 버튼 이름 | 연결 목적지 | 현재 확보 상태 |

| 푸터가 브랜드·저작권만 포함 | 공식 운영 주체, 연락처, 정책, SNS·주요 링크 추가 |
| 모바일 상단 메뉴 숨김 | 모든 주요 영역에 접근하는 모바일 메뉴 제공 |

## 14. 제작 전 자료 확보 우선순위

### 14.1 기본 브랜드 화면 작성에 필요한 자료

- 공식 로고와 브랜드 이미지, 표기 기준.
- 공개할 브랜드 소개·교육 철학·성장 경로의 문구 확정.
- 연혁과 현재 지점 목록의 공식 명칭·운영 여부.
- HARU 현재 주소, 공식 SNS, 문의 채널.
- 푸터에 들어갈 운영 주체·대표 연락처·정책 문서.

### 14.2 예약·신청·지원 기능을 공개하기 전에 필요한 자료

- 지점별 주소·운영시간·전화번호·네이버 예약 URL.
- 지점별 디자이너와 스타일 사진·설명.
- 실제 교육명·강사·대상·커리큘럼·날짜·장소·비용·신청 방식.
- 교육 준비물·결제·취소 안내의 운영 기준.
- 실제 채용공고·근무 조건·지원 수단·담당 채널.
- 산학협력 담당 채널과 공식 문의 방식.
- 마켓 링크의 목적지와 대표 상품 연결 확인.
- 자체 양식을 사용한다면 실제 접수 수단과 입력·동의 안내.

### 14.3 추가하면 이해와 신뢰를 높일 수 있는 자료

- 공개 가능한 산학협력 사례와 기관 이미지.
- 강사진의 원본 사진·최신 이력과 운영진 소개.
- 실제 교육 현장 기록과 수강자의 공개 가능한 후기.
- 구성원의 성장 인터뷰와 지점별 스타일 포트폴리오.

**콘텐츠 준비의 완료 기준:** 브랜드 소개 문구만 있는 화면을 넘어 방문자가 지점·교육·채용 정보를 판단할 수 있고, 각 버튼이 해당 정보에 맞는 유효한 예약·신청·문의 수단으로 연결되는 상태를 목표로 한다. 제공되지 않은 운영 정보는 이 문서의 자료 준비 목록으로 관리한다.
